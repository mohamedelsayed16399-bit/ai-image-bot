# بوت الصور بالذكاء الاصطناعي 🎨

بوت **مجاني 100%** لإنشاء الصور من أي وصف، وتعديل أي صورة بكتابة التعديل المطلوب - زي Gemini في الصور، بس بكود مفتوح ومن غير أي فلوس أو اشتراكات.

## بيعمل إيه؟

- **إنشاء صور من الوصف**: اكتب «أسد بيلبس نضارة على شاطئ الإسكندرية» وخد الصورة.
- **تعديل الصور بالكلام**: ارفع صورة واكتب «خلي الخلفية شاطئ» أو «حوّلها لأنمي».
- **واجهة ويب شبه Gemini**: شات بسيط يشتغل على الموبايل والكمبيوتر.
- **بوت تليجرام (اختياري)**: لو عايز نفس البوت على تليجرام.
- **ستايلات جاهزة**: واقعي، أنمي، لوحة زيتية، لوجو، ملصق، سايبربانك، 3D.
- **من غير تسجيل ولا API keys**: الخدمات المجانية اللي جواه شغالة على طول.

## التشغيل (3 خطوات)

محتاج [Node.js](https://nodejs.org) نسخة 18 أو أحدث بس. مفيش `npm install` - المشروع من غير مكتبات خارجية خالص.

```bash
node bot.js
```

وافتح المتصفح على: **http://localhost:3000**

### على موبايل أندرويد (Termux)

```bash
pkg install nodejs git
git clone https://github.com/mohamedelsayed16399-bit/ai-image-bot.git
cd ai-image-bot
node bot.js
```

وافتح في المتصفح: **http://localhost:3000**

## بوت التليجرام (اختياري)

1. افتح تليجرام وكلم `@BotFather` وابعت `/newbot` وسمّي البوت - هيديك **توكن**.
2. شغّل البوت بالتوكن:

```bash
# على لينكس/ماك/Termux
TELEGRAM_TOKEN=التوكن_هنا node bot.js

# على ويندوز (PowerShell)
$env:TELEGRAM_TOKEN="التوكن_هنا"; node bot.js
```

3. في تليجرام: ابعت أي كلام لإنشاء صورة، وابعت صورة مع كابشن لتعديلها، أو رد على صورة بـ `/edit التعديل`.

## إزاي شغال مجانًا؟

البوت بيستخدم خدمتين مجانيتين بجد، من غير مفاتيح:

| الخدمة | الاستخدام | التسجيل |
|---|---|---|
| [Pollinations.ai](https://pollinations.ai) (موديل Sana) | إنشاء الصور (سريع) | مش محتاج |
| [Stable Horde](https://stablehorde.net) (كروت متطوعين) | إنشاء + تعديل الصور | مش محتاج |

لو خدمة وقعت، البوت بيجرّب التانية لوحده.

## حدوده بصراحة

- الجودة كويسة جدًا لمعظم الاستخدامات، بس مش مستوى Gemini/Imagen في التفاصيل الدقيقة - دي موديلات مجانية.
- التعديل بيعتمد على Stable Horde (كروت شاشة متطوعين)، فممكن يستنى دقيقة-دقيقتين وقت الزحمة.
- الصور بتتبعت للخدمات دي عشان تتعالج - متبعتش صور شخصية حساسة.
- التعديل بيعيد رسم الصورة بنسبة (قوة التعديل)، فمش بيحافظ على التفاصيل 100% زي التعديل الاحترافي.

## خصوصية

مفيش أي حاجة بتتخزن - الصور بتتولّد وبتتبعتلك على طول. الكود كله مفتوح ومفيش فيه مفاتيح أو حسابات.
